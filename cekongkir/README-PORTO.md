# Cek Ongkir — Galeri Tema (Versi Demo Portofolio)

Ini adalah **versi demo portofolio** dari eksplorasi UI/UX halaman "Cek Ongkir" — data dummy,
tanpa kredensial, dan tidak terhubung ke sistem live manapun.

Semua halaman di sini adalah **purwarupa statis** (HTML/CSS murni, tanpa backend), hasil eksplorasi
desain untuk beberapa gaya visual berbeda dari brief yang sama:

- `sicek/` — 3 varian: `signature`, `nova`, `landing-page` (landing-page sudah live di
  cekongkirmurah.smsrm.com)

## Cara Membuka

Buka `index.html` di root folder ini — halaman itu adalah **galeri pemilih tema** yang
menampilkan semua varian sebagai kartu, sehingga tidak perlu tahu struktur folder aslinya untuk
menjelajahi tiap desain.

## Catatan

- Tidak ada data bisnis riil di folder ini — semua kontennya adalah teks/gambar contoh dari proses
  desain, bukan hasil ekstraksi data internal perusahaan.
- Folder `graphify-out/` (jika ada) adalah cache hasil analisis proyek dan tidak relevan untuk
  ditampilkan sebagai portofolio — abaikan.
