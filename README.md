## 🏛️ Arsitektur & Struktur Portofolio

Portofolio ini dirancang menggunakan konsep **Unified Hub**, membagi seluruh rekam karya ke dalam 2 pilar besar dengan navigasi terintegrasi:

```
mmgufrons.github.io/
├── index.html                    # Root Hub: Gerbang utama dwibahasa (Business & AI Ops + Creative)
├── assets/
│   ├── js/i18n.js                # Core Engine Bilingual Client-Side (556 kunci simetris ID ⇄ EN)
│   └── css/                      # Desain sistem global, token warna & utilitas
│
├── 💼 PILAR 1: BUSINESS & AI OPERATIONS
│   ├── mkt/                      # Marketing Operations Suite (MKT.OS)
│   │   ├── index.html            # Hub Utama Suite Marketing (7 Modul Terintegrasi)
│   │   ├── admin_panel.html      # 1. Admin Panel & Manajemen Data Ekosistem
│   │   ├── partner/b2b.html      # 2. B2B Partnership Board (Pipeline CRM Inbound/Outbound)
│   │   ├── mitra/tracker.html    # 3. Mitra Onboarding & Field Canvassing Tracker
│   │   ├── campaign/...          # 4. Campaign Leads Cleanser & CRM Broadcast Tracker
│   │   ├── data/ppob/            # 5. PPOB Financial Ops Dashboard (Pulsa, PLN, Trx)
│   │   ├── data/mp-report/       # 6. Marketplace & Live Commerce Performance Analytics
│   │   ├── tools/legal/          # 7. Legal Document Management System (LDMS)
│   │   └── tools/banner/         # Smart Generator Banner Agen & Kemitraan
│   │
│   ├── sma/                      # SMA Enterprise Workstation (Internal Company ERP)
│   │   └── index.html            # Daily Task, Team Messaging & Operations Directory
│   │
│   ├── cekongkir/                # Multi-Expedition Cost Calculator & Tracking (SiCek UI)
│   ├── apidocs/                  # Dokumentasi API Terbuka untuk Mitra Kemitraan B2B
│   ├── lpqris/                   # Solusi Konversi QRIS Statis ke Dinamis dengan Soundbox
│   └── panduan/                  # Portal Dokumentasi SOP per Peran (Agen, Seller, B2B)
│
└── 🎨 PILAR 2: CREATIVE & VISUAL DESIGN
    ├── desain/index.html         # Katalog Galeri Desain Klasik & Identitas Visual
    └── desain/portfolio-single-* # 12 Halaman Detail Studi Kasus & Brand Identity
```

## ⚡ Sorotan Rekayasa Teknis

1. **Mesin Dwibahasa Client-Side (`assets/js/i18n.js`)**:
   - Beroperasi tanpa dependensi pihak ketiga (*vanilla JavaScript*).
   - Menyediakan **556 kunci kamus** dengan **100% paritas 1:1 antara Bahasa Indonesia dan Bahasa Inggris**.
   - Menyimpan preferensi bahasa di `localStorage` dan merender pergantian bahasa secara instan ke seluruh atribut `data-i18n`, teks konten, hingga placeholder input tanpa me-reload halaman.

2. **Arsitektur Tanpa Server (Serverless Static Demo)**:
   - Modul yang awalnya berbasis PHP telah dimigrasikan secara rapi menjadi halaman statis interaktif yang berjalan mulus di GitHub Pages.
   - Menggunakan `localStorage` dan fallback data dummy realistis sehingga seluruh fungsionalitas (tambah baris, filter kategori, alih tab, kalkulasi omzet) tetap bisa diuji coba secara interaktif oleh publik tanpa memerlukan instalasi database lokal.

3. **Standar Kontras Tinggi & Aksesibilitas (WCAG AAA)**:
   - Didesain dengan palet warna terkurasi: Obsidian Dark (`#09090b`), Deep Violet (`#140927`), Slate Border (`#27272a`), dan aksen oranye terang khas SIMASRIM (`#F3700D`).
   - Tombol navigasi dan badge menggunakan rasio kontras > 14:1 untuk memastikan kenyamanan baca maksimal di berbagai resolusi layar maupun kondisi pencahayaan.
