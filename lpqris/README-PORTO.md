# QRIS Statis2Dinamis — Landing Page (Versi Demo Portofolio)

Landing page pemasaran layanan konversi QRIS statis ke dinamis.

## Apa yang Didummy-kan

Form pendaftaran di halaman ini aslinya meneruskan data pengunjung (nama, email, WA) ke nomor
WhatsApp admin asli lewat redirect `wa.me`. Nomor tersebut sudah **dihapus total**, diganti nomor
dummy (`6280000000000`) — mengisi form demo ini tidak akan mengirim data ke siapa pun di dunia
nyata.
