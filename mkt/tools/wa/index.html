💾 Data offline (JSON)

Kumpulan kontak, grup, dan template kamu bisa juga disimpan sebagai satu file JSON di komputer kamu — file itu bisa dibuka & diedit langsung pakai teks editor biasa, lalu dimuat lagi ke halaman ini kapan saja (misal untuk pindah ke komputer lain).

Lihat format JSON (untuk edit manual) 
{
  "pool": {
    "headers": ["Nama", "Nomor WA", "Lokasi"],
    "rows": [
      { "Nama": "Budi", "Nomor WA": "0812xxxxxxx", "Lokasi": "Bogor" }
    ]
  },
  "groups": {
    "kontak:pelanggan_juli": {
      "name": "Pelanggan Juli",
      "headers": ["Nama", "Nomor WA", "Lokasi"],
      "rows": [ { "Nama": "Budi", "Nomor WA": "0812xxxxxxx", "Lokasi": "Bogor" } ],
      "colNomor": "Nomor WA",
      "colNama": "Nama"
    }
  },
  "templates": {
    "template:promo_juli": {
      "name": "Promo Juli",
      "text": "Halo {{Nama}}, ada promo khusus buat kamu!",
      "attachment": null
    }
  }
}

Kirim ke -

Buka web.whatsapp.com dan login (scan QR) sekali di tab terpisah, biarkan tetap terbuka. Setelah itu, setiap kontak yang kamu kirim dari sini akan memakai tab WhatsApp Web yang sama — chat-nya berganti otomatis, tanpa membuka tab baru terus-menerus.

📎 Ada lampiran di pesan ini. WhatsApp tidak bisa menerima file lewat link secara otomatis — unduh file di bawah lalu seret (drag & drop) ke kotak chat WhatsApp setelah teks pesan terbuka, sebelum menekan kirim.
🔁 Kirim otomatis, satu tab
Klik mulai. Tiap beberapa detik, tab WhatsApp Web yang sama otomatis pindah ke chat kontak berikutnya dengan pesan sudah terisi. Kamu tinggal duduk di tab WhatsApp dan tekan Enter tiap kali chat berganti.
➡️ Mode berurutan (manual)
Satu kontak ditampilkan bergantian. Klik "Kirim & Lanjut" saat kamu siap — chat tetap terbuka di tab WhatsApp Web yang sama, tidak berpindah tab baru.
Pastikan tab web.whatsapp.com sudah terbuka dan sudah login sebelum mulai. Kalau muncul peringatan "pop-up diblokir" saat pertama kali, klik ikon di address bar dan pilih izinkan pop-up untuk situs ini.
